# bulevo-harness

Harness для [Claude Code](https://code.claude.com): плагины, с которыми агенты работают как внимательные
инженеры — разбираются в проблеме, критически читают требования, переиспользуют существующий код и
доказывают, что всё работает. Плюс инструменты, которые показывают, помогает ли каждое изменение harness.

> **Статус: ранний, экспериментальный.** Плагин в версии v0.1 и часто меняется.

## Установка

В сессии Claude Code:

```
/plugin marketplace add LevButkovskiy/bulevo-harness
/plugin install bulevo@bulevo-harness
```

Выберите скоуп **User**, чтобы плагин работал во всех проектах. Обновление:

```
/plugin marketplace update bulevo-harness
```

## Использование

### `/bulevo:task <задача>`

Запускайте в начале задачи, до того как написан код. Скилл:

1. Отличает «разберись» от «сделай». На «выясни, почему…» отвечает с доказательствами и ничего не меняет.
2. Изучает код через сабагента `scout` на более дешёвой модели, который только читает: что переиспользовать,
   какому паттерну следовать и все места, которые затронет изменение.
3. Разбирает требования: какую проблему решает задача, противоречия, краевые случаи, побочные эффекты и
   решение проще.
4. Задаёт только те вопросы, от ответа на которые зависит код.
5. Пишет спецификацию в `.claude/tasks/<дата>-<название>.md` с проверяемыми критериями приёмки и ждёт
   вашего подтверждения.

Реализацию по утверждённой спеке запускайте в новой сессии, например: `Реализуй .claude/tasks/<файл>.md`.

Работает и в отдельном репозитории, и в папке, где лежат несколько репозиториев.

### Настройки

Необязательный файл `.claude/bulevo.json` в проекте:

```json
{ "pushback": "balanced" }
```

| `pushback` | Поведение |
|---|---|
| `quiet` | Спрашивает только при явном противоречии; сомнения записывает в спеку |
| `balanced` (по умолчанию) | Спрашивает, когда ответ меняет код; предлагает лучшую альтернативу; останавливается при риске для данных, безопасности, денег или юридических требований |
| `strict` | Спрашивает при любой неясности; останавливается и тогда, когда задача, скорее всего, не решит исходную проблему |

## Репозиторий

| Путь | Что там |
|---|---|
| `plugins/bulevo/` | Плагин |
| `docs/requirements.md` | Что harness должен требовать от агентов и почему |
| `tools/transcripts/` | Разбор ваших транскриптов Claude Code: где агента приходилось поправлять |
| `evals/` | Замер изменений harness; сейчас это спайк с Harbor и `claude plugin eval` |

Тем, кто дорабатывает harness с помощью Claude Code: см. [CLAUDE.md](CLAUDE.md).
